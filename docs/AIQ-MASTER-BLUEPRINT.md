## 2. The Idea Intake Protocol (The 4 Boxes)

Every new idea, API, or project must be classified into one of four boxes. Unplanned architecture expansion is forbidden.

1. **NOW:** Immediate execution block (e.g., Factory Testing, GitHub Playbook).
2. **NEXT:** Queued for the upcoming cycle (e.g., Control Center MVP).
3. **LATER:** Registered for future review (e.g., Meta Ads API).
4. **NO ACTION:** Rejected or discarded.
