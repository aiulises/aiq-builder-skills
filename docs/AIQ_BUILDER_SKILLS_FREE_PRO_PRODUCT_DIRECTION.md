# AIQ Builder Skills — Free & Pro
**Status:** Public product direction / concept, not a released paid product
**Creator:** Ulises Garcia · AIQ Labs
**Tagline:** From idea to secure software.

## What is AIQ Builder Skills?
A visual-first way to learn how to plan, build, test and improve real software with AI coding tools. Designed for beginners and practical builders using ChatGPT, Claude Code, Codex and similar tools. Explain technology with familiar real-world metaphors, then show the actual file, command, test and proof.

**Example:** index.html is the front door; src/ is the workshop; components/ are reusable workstations; a database is the records archive; authorization decides who gets which keys. These metaphors teach concepts; they are not substitutes for secure implementations.

## Free / public — community edition
- Quick-start: idea -> PRD -> inspect existing repo -> small implementation -> tests -> review -> explicit release approval.
- Beginner-friendly visual explanations and safe, synthetic examples.
- A sample audit checklist: ALREADY EXISTS / PARTIAL / MISSING / LEGACY / DO NOT REBUILD.
- A sample skill demonstrating clear instructions, evidence, test criteria and limitations.
- Links to the existing canonical skills without silently changing their frozen V1 status.

## Pro / paid — proposed, not yet available
- Curated step-by-step playbooks for SaaS architecture, auth, tenant isolation, test isolation, data migrations, backups, release and rollback.
- Editable project templates, review rubrics, device QA matrices, exercises and guided examples.
- A visual architect learning path and practical implementation case studies with synthetic data.
- Optional course, updates and consulting. Availability, pricing, license, support and refund terms to be decided and published before sales.

## Why it is different
1. **Visual understanding** before memorizing commands.
2. **Audit before build** to avoid duplicate work.
3. **Evidence over claims**: test results, reproducible steps and known unknowns.
4. **Safety from day one**: least privilege, tenant separation, secrets hygiene and rollback.
5. **Human approval** for meaningful actions.
6. **Reusable lessons**: improve the playbook after real, verified fixes.
