### OCTOBER — MAKE THE FACTORY WORK 🏭
**Goal:** Prove the Golden Path on a single task from problem → verified fix.

- Finalize the **GitHub Agent Playbook** and **Developer Portal**.
- Prove **Cold Developer Test** (GitHub alone, no chat).
- Setup **Grok Bot** with Eyes + Hands (Browser/Mobile human test-path).
- Setup **Claude Code** with Xcode/Mac test-path.
- Test **HairPlan.PRO first** from start to end.
- Scale Human Test protocol to **HairPlan Me** and **Lead Radar**.

**October Gate:** `AI Operator — BUILD VERIFIED ✅` 
*(Requires commit SHA, test output, screenshots, runtime evidence, and ULISES GO).*

### NOVEMBER — MAKE THE FACTORY REPEATABLE 🔁
**Goal:** The factory processes multiple products systematically without manual re-engineering.

- Standardize App Intake:
  - Architecture map → Relevant skills → Build commands → Test environment → Human flows → Security → Performance → UI/UX → Evidence report.
- Introduce **Shopify** as a destination adapter (AIQ Factory → Shopify).
- First **external repo test** (Audit → Fix → Human Test → PR).
- Start measuring factory unit economics: credits, tokens, hours, retries, errors, human intervention, cost per verified fix.

**November Gate:** `AIQ Factory — REPEATABLE ✅`

### DECEMBER — MAKE THE FACTORY EARN 💰

  - **Engineer 🧠:** Architecture, security, dependencies.
  - **Human 👁️🖐️:** UI/UX, mobile flow, taps, clicks.

**December Gate:** `WORKING → PAID → REPEATABLE ✅`
